# AI Hub

AI Hub is a modular, scalable, and production-ready AI-powered web browser platform.

This repository contains a monorepo scaffold with frontend and backend packages to bootstrap the project.

Features included in this scaffold:
- React + Vite + TypeScript frontend with Tailwind CSS
- Express + TypeScript backend with MongoDB and Redis integrations
- Secure /api/proxy endpoint with SSRF/XSS protections, caching, and rate limiting
- JWT authentication scaffolding
- Socket.io streaming adapter for AI assistant
- Monaco Editor integration in the Code Studio page
- Basic pages: Home, Browser, AI Chat, Image Studio, Code Studio, Documents, History, Downloads, Bookmarks, Extensions, Profile, Settings

This is the initial scaffold. Fill environment variables in .env and follow the README to run locally.
